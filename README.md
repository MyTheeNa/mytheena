### 👋 About me

I'm a **self-proclaimed lazy developer** — if a task has to be done more than once, I'd rather build a system that does it for me. So I spend my time creating **automation tools and apps that make daily life more convenient**.

- 🇹🇭 Based in Thailand
- 🎂 16 years old
- ⚙️ Into automation, bots, and full-stack web apps
- 💡 Motto: *"Why do it by hand when code can do it for you?"*

### 🚀 What I build

- 🤖 **Automation systems** that take repetitive, everyday tasks off my plate
- 🌐 **Full-stack web apps** — Next.js · TypeScript · PostgreSQL
- 💬 **Bot & API integrations** — LINE Messaging API, payment/slip automation
